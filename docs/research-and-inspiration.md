## Architecture comparison

| Option | Capability / cost | Decision |
|---|---|---|
| Plain DOM/CSS + GSAP | Smallest runtime; good for one paper narrative. Seven complex evidence interactions need careful manual state/cleanup and structured content binding | Viable; slightly more bespoke state coordination |
| React + Vite + TypeScript + GSAP | Semantic DOM, seven isolated modules, central typed content, reusable controls, scoped reversible scroll effects | **Chosen.** Simplest maintainable fit for the requested interactive academic content |
| Three.js/WebGL or PixiJS | Spatial world or shader/frame choreography; canvas accessibility, device/GPU/startup cost, assets and render lifecycle | Rejected: paper/annotations are more directly communicative; 3D cannot justify the extra cost |

Native scrolling was retained. Lenis is not installed: no tangible benefit offsets another animation clock and anchor/restoration complexity. GSAP handles only decorative transforms and accurate-data bar entry. The final paper uses CSS sticky; phones flatten it. No starter was copied.

## Current API / compatibility / licensing check

- [GSAP ScrollTrigger docs](https://gsap.com/docs/v3/Plugins/ScrollTrigger/): register plugin, scrub ties progress to native scroll; gsap.context and matchMedia provide scoped cleanup. refresh recalculates geometry. Implementation uses reversible transforms and matchMedia, not scroll interception. Installed GSAP 3.15.1, package's [standard no-charge license](https://gsap.com/standard-license/) retained. This is not mislabelled MIT.
- [Lenis](https://github.com/darkroomengineering/lenis): README documents ticker/ScrollTrigger integration and native scrolling considerations; MIT. Not installed.
- [Vite guide](https://vite.dev/guide/): Node requirements checked against local Node 24.14.0; Vite 7.3.7 installed and build verified. React 19 and TypeScript 5.9 used.
- [Three.js](https://threejs.org/) and [PixiJS](https://pixijs.com/): current docs inspected, both have MIT code licenses. Neither installed; asset licensing would remain separate. Motion not needed.
- Runtime dependencies are React/ReactDOM (MIT) and GSAP (standard license). Every original illustration is CSS/SVG authored for this artifact. OS fonts carry their host-system licenses; no font files redistributed.
